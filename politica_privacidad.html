Política de Privacidad

En cumplimiento del Reglamento (UE) 2016/679 (RGPD) y la Ley Orgánica 3/2018 de Protección de Datos Personales y garantía de los derechos digitales (LOPDGDD), se informa a los usuarios sobre el tratamiento de sus datos personales.

1. Responsable del tratamiento

  • Titular: Lorenzo Drovandi
  • Correo electrónico: lorenzodrovandi17@gmail.com
  • Sitio web: https://lorenzodrovandi7.github.io/lorenzo-drovandi/

2. Datos que se recogen

Este sitio web recoge los siguientes datos personales:

2.1. Datos facilitados voluntariamente

A través del formulario de contacto se recogen:

  • Nombre
  • Correo electrónico
  • Empresa (opcional)
  • Tipo de proyecto (opcional)
  • Mensaje

2.2. Datos técnicos de navegación

Pueden recopilarse datos técnicos de navegación (como dirección IP, tipo de navegador o dispositivo) de forma automática por el proveedor de hosting o herramientas técnicas necesarias para el funcionamiento del sitio.

3. Finalidad del tratamiento

3.1. Formulario de contacto

Los datos recogidos en el formulario de contacto se utilizan exclusivamente para:

  • Responder a la consulta o solicitud del usuario
  • Gestionar la comunicación iniciada por el usuario

3.2. Datos técnicos

Los datos técnicos que puedan recopilarse se utilizan exclusivamente para:

  • Garantizar el correcto funcionamiento del sitio web
  • Mejorar la seguridad y estabilidad del servicio
  • Analizar de forma agregada el rendimiento técnico

4. Base legal

4.1. Formulario de contacto

La base legal para el tratamiento de datos del formulario de contacto es el consentimiento explícito del usuario, prestado al enviar el formulario. El usuario puede retirar su consentimiento en cualquier momento solicitando la eliminación de sus datos.

4.2. Datos técnicos

La base legal para el tratamiento de datos técnicos es el interés legítimo del titular en el mantenimiento y funcionamiento seguro del sitio web.

5. Conservación de los datos

5.1. Formulario de contacto

Los datos del formulario se conservarán durante el tiempo necesario para atender la consulta y hasta 1 año después. Una vez cumplida la finalidad, se suprimirán.

5.2. Datos técnicos

Los datos técnicos no se almacenan por el titular del sitio web, sino por los proveedores de infraestructura (hosting, CDN u otros servicios técnicos) durante los plazos establecidos por dichos proveedores.

6. Comunicación de datos

Los datos del formulario se transmiten a Formspree (https://formspree.io) únicamente para hacer llegar el mensaje al titular. Formspree actúa como encargado del tratamiento, lo que puede implicar transferencia internacional de datos fuera del EEE amparada en las garantías ofrecidas por dicho proveedor. No se ceden datos a terceros con otros fines, no se venden y no hay cesiones salvo obligación legal.
